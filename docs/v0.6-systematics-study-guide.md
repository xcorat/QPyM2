# QPyM2 v0.6: Systematics Studies & Rate Marginalisation Guide

This document describes the physics context, mathematical formulation, configuration schema, and storage architecture for systematic studies and rate marginalisation in QPyM2 `v0.6.0`.

---

## 1. Overview & Physics Context

In the CUORE Multiplicity-2 (M2) analysis, two crystals fire in coincidence within a 100 ms event window. An extended unbinned maximum likelihood fit is performed in rotated energy coordinates $(u, v) = ((E_1 + E_2)/\sqrt{2}, (E_1 - E_2)/\sqrt{2})$ to measure or set limits on the rate of neutrinoless double beta decay ($0\nu\beta\beta$, denoted `ndbd`) in $^{130}\text{Te}$.

To extract the physical decay rate $\Gamma_{0\nu}$ [$\text{yr}^{-1}$] and a 90% C.L. lower limit on the half-life $T_{1/2}^{0\nu}$ [$\text{yr}$], all experimental and modeling systematic uncertainties must be evaluated, translated into count-level shifts on the $0\nu\beta\beta$ posterior, combined in quadrature, and propagated to a marginalized rate posterior convolved with detection and pulse shape analysis (PSA) efficiencies.

### 1.1 Transition to v0.6 Architecture

Historically, systematics were evaluated through disparate scripts (`run_syst_lss.py`, `run_syst_mc.py`, `run_ndbd_shift_syst.py`) and ad-hoc Jupyter notebooks (`notebooks/old/build_code/*.ipynb`, `notebooks/old/tests/*.ipynb`). Intermediate outputs were saved across non-standard directories, and the final rate marginalisation notebook (`06-syst-rate-new.ipynb`) required manually copy-pasting numbers into hardcoded arrays.

The **QPyM2 v0.6 storage and study framework** unifies these disparate workflows:
1. **Geometry-Encoded Storage**: Coordinate hierarchy `roi_<min>_<max>/thr<val>/<coord>_b<bin_size>/input|output/` houses reusable templates, observed data, and fit outputs.
2. **Deterministic Hashing**: 12-character SHA-256 UUIDs (`<input_UUID>`, `<output_UUID>`) guarantee that parameter variations are reproducible and cache-checked.
3. **Declarative Study Orchestration**: Studies are configured via `study.yaml`, loaded through the 4-tier Hydra system, and managed through `Study` and `run_study.py`.
4. **Decoupled Worker Aggregation**: Worker tasks write independent task files to `<study_dir>/tasks/`, which a collector merges into `results.csv` and indexes in `<study_name>.sqlite`.

## 2. Taxonomy of Systematics

Based on the CUORE M2 tech note analysis and historical studies, systematic uncertainties are categorized into **eight primary classes**, followed by a final combination and marginalisation stage.

| # | Systematic Class | Identifier | Source of Uncertainty | Mechanism & Evaluation |
|---|---|---|---|---|
| 1 | **LSS Q-Residual** | `lss_dq` | Calibration curve polynomial residual per dataset | Draws random parameter vectors from dataset covariance matrices (`lss_params`); transforms staged events; fits per dataset with nominal priors |
| 2 | **LSS Sigma-Scaling** | `lss_sscl` | Energy resolution scaling uncertainty across datasets | Evaluates fixed $\pm 1\sigma$ variations (`sscale_1r`, `sscale_1l`); applies stochastic Gaussian smearing per event; fits per dataset |
| 3 | **BM MC Normalisation** | `bmmc` / `bm_norm` | Finite statistics and correlations in JAGS background model components | Samples $N=100\text{--}500$ normalisation vectors from JAGS chain perturbed by background correlation matrix; fits with PyMC; resamples with log-likelihood weights |
| 4 | **BM Reconstruction Setup** | `bm_threshold`, `bm_binning` | Upstream background model fit choices | Compares nominal (`Threshold200`) against `Threshold250` (modifies fit region to `thr250`) and binning variants (`MinBinSize_5_20`, `MinBinSize_25_60`, `BinningIntraAlphaBands`) |
| 5 | **Template Likelihood Binning** | `bin_size` | Resolution of 2D histogram templates in likelihood | Rebuilds templates at coarser binning (e.g. 2.0 or 5.0 keV in $u/v$ vs nominal 1.0 or 2.5 keV); fits with nominal-bin priors |
| 6 | **Template Smoothing** | `smoothing` | 2D kernel smoothing on background templates | Fits with alternate smoothing configurations (e.g., `smooth_nph2` with varied bandwidth vs un-smoothed) |
| 7 | **Coordinate Energy Shifts** | `co_shift`, `ndbd_shift` | Energy calibration offsets in the ROI | Shifts $^{60}\text{Co}$ background template or $0\nu\beta\beta$ signal template across $[0.0, 0.8, 1.0, 1.2, 1.5]$ keV |
| 8 | **Toy Bias Calibration** | `bias_corr` | Uncertainty in toy signal-injection linear calibration $(a, b)$ | Propagates parameter covariance $\text{pcov}$ of calibration line $y = a \cdot x + b$ |
| 9 | **Rate Marginalisation** | `syst_rate` | Exposure and PSA efficiency uncertainty | Convolves smeared count posterior with exposure and $\epsilon_{\text{PSA}} \sim \mathcal{N}(\mu_{\text{PSA}}, \sigma_{\text{PSA}})$ |

## 3. Mathematical Formulation

The combination and marginalisation workflow follows the methodology implemented in `qpym2.syst` (`core.py`, `smear.py`, `rate.py`):

```
       [Nominal Fit Trace]
               │
               ▼
      [Deterministic Bias Correction]
      N_bc = (N_raw - b) / a
               │
               ▼
 ┌─────────────────────────────┐
 │ Systematic Trace Evaluation │
 │  - LSS dQ                   │
 │  - LSS sigma-scale          │
 │  - BM-MC Normalisation      │ ──► Compute Delta Shifts:
 │  - BM Threshold / Binning   │     Δright = max(0, HDI_hi^syst - HDI_hi^nom)
 │  - Coordinate Shifts        │     Δleft  = min(0, HDI_lo^syst - HDI_lo^nom)
 │  - Bin Size / Smoothing     │
 └─────────────────────────────┘
               │
               ▼
 ┌────────────────────────────────────────────────────────┐
 │ Independent Quadrature Summation                       │
 │   σ_right = sqrt( sum( (Δright_i)^2 ) )               │
 │   σ_left  = -sqrt( sum( (Δleft_i)^2 ) )                │
 └────────────────────────────────────────────────────────┘
               │
               ▼
 ┌────────────────────────────────────────────────────────┐
 │ Split-Gaussian Smearing & Low-Edge Extension           │
 │   - Skew-normal / KDE extension below 2nd percentile   │
 │   - Sample split-Gaussian: d ~ N(0, σ_right/left)      │
 │   - N_smeared = N_extended + d                         │
 └────────────────────────────────────────────────────────┘
               │
               ▼
 ┌────────────────────────────────────────────────────────┐
 │ Rate Conversion & PSA Marginalisation                  │
 │   Γ = N_smeared / (F130 · N_TeO2 · Exp · eff_MC · eff_PSA)│
 │   where eff_PSA ~ N(μ_PSA, σ_PSA)                      │
 └────────────────────────────────────────────────────────┘
               │
               ▼
 ┌────────────────────────────────────────────────────────┐
 │ Physics Inferences                                     │
 │   - Mode decay rate Γ_mode                             │
 │   - 68.27% HDI interval on Γ                           │
 │   - 90% C.L. Bayesian upper limit Γ_90                 │
 │   - 90% C.L. lower limit on half-life T_1/2 = ln2/Γ_90  │
 └────────────────────────────────────────────────────────┘
```

### 3.1 Mode and 1-Sigma Edge Delta Shifts

For a systematic variant with bias-corrected posterior $P_{\text{syst}}(N)$ compared against nominal bias-corrected posterior $P_{\text{nom}}(N)$:

1. **Mode Shift**:
   $$\Delta_{\text{mode}} = \text{mode}(P_{\text{syst}}) - \text{mode}(P_{\text{nom}})$$

2. **1-Sigma HDI Edge Extensions**:
   With $\text{HDI}_{68}(P) = [N_{\text{lo}}, N_{\text{hi}}]$:
   $$\Delta_{\text{right}} = \max\left(0,\, N_{\text{hi}}^{\text{syst}} - N_{\text{hi}}^{\text{nom}}\right)$$
   $$\Delta_{\text{left}}  = \min\left(0,\, N_{\text{lo}}^{\text{syst}} - N_{\text{lo}}^{\text{nom}}\right)$$

By convention, $\Delta_{\text{right}} \ge 0$ represents upward expansion of the uncertainty band, and $\Delta_{\text{left}} \le 0$ represents downward expansion.

### 3.2 Quadrature Combination

Systematic deltas on each side are summed in quadrature independently so that asymmetric systematics contribute only to the direction they push the posterior:

$$\sigma_{\text{right}} = \sqrt{\sum_{i=1}^M \left(\Delta_{\text{right}}^{(i)}\right)^2}, \qquad \sigma_{\text{left}} = \sqrt{\sum_{i=1}^M \left(\Delta_{\text{left}}^{(i)}\right)^2}$$

### 3.3 Low-Edge Extension and Split-Gaussian Smear

Because physical counts satisfy $N \ge 0$, naive smearing around zero causes pileup and artificial mode shifts. The algorithm (`extend_skew_norm` in `qpym2.syst.smear`):
1. Identifies the lower tail (e.g. 2nd to 45th percentile) of the nominal bias-corrected posterior.
2. Fits a skew-normal distribution to the truncated lower region.
3. Generates smoothly extended samples below the physical cutoff into negative space.
4. Convolves the extended distribution with an asymmetric split-Gaussian perturbation:
   For each sample $x$, draw $u \sim \text{Uniform}(0, 1)$:
   $$d = \begin{cases} +|z_{\text{right}}|, & z_{\text{right}} \sim \mathcal{N}(0, \sigma_{\text{right}}^2) \quad \text{if } u > 0.5 \\ -|z_{\text{left}}|, & z_{\text{left}} \sim \mathcal{N}(0, \sigma_{\text{left}}^2) \quad \text{if } u \le 0.5 \end{cases}$$
   $$N_{\text{smeared}} = x + d$$

### 3.4 Rate & Half-Life Conversion

Samples with $N_{\text{smeared}} \ge 0$ are converted to decay rate $\Gamma_{0\nu}$ [$\text{yr}^{-1}$]:

$$\Gamma = \frac{N_{\text{smeared}}}{F_{130} \cdot N_{\text{TeO}_2} \cdot \text{exposure} \cdot \epsilon_{\text{MC}} \cdot \epsilon_{\text{PSA}}}$$

Constants and parameters:
- $F_{130} = 0.34167$: Isotopic abundance of $^{130}\text{Te}$ in natural tellurium.
- $N_{\text{TeO}_2} = \frac{6.022 \times 10^{23} \times 1000}{159.6} \approx 3.773 \times 10^{24}$ molecules/kg.
- $\text{exposure}$: CUORE M2 exposure in $\text{kg}\cdot\text{yr}$ (nominal: $1038.4\,\text{kg}\cdot\text{yr}$).
- $\epsilon_{\text{MC}}$: Signal selection efficiency from MC (evaluated via `read_ndbd_eff`).
- $\epsilon_{\text{PSA}} \sim \mathcal{N}(\mu_{\text{PSA}}, \sigma_{\text{PSA}})$: Pulse shape analysis efficiency (nominal: $\mu=0.99, \sigma=0.01$).

The 90% C.L. Bayesian lower limit on the $0\nu\beta\beta$ half-life is:
$$T_{1/2}^{0\nu} = \frac{\ln 2}{\Gamma_{90}}$$
where $\Gamma_{90}$ is the 90th percentile of the marginalized rate posterior.

## 4. Configuration Schema (`study.yaml`)

Under `v0.6`, every study is defined declaratively by a `study.yaml` file. We support two primary patterns:
1. **Component-Specific Systematic Study**: Executes an individual systematic sweep (e.g. LSS across datasets, BM normalisation sampling).
2. **Master Systematic Rate Study**: Collects deltas across individual studies (or explicit delta values), combines in quadrature, and computes marginalized rates and half-life limits.

### 4.1 Component-Specific Systematic Study (`studies/example_lss_study/study.yaml`)

```yaml
study:
  name: example_lss_study
  type: syst
  description: "LSS Q-residual and sigma-scaling systematic fits for tech_note_200"

defaults:
  environment: local
  staging: default
  analysis: base
  models: tech_note
  model_key: tech_note_200

reference:
  co_cut: gamma10_v150
  ndbd_cutoff: u1740
  co_shift: 1.0
  ndbd_shift: 0.0
  blinded: false

syst:
  category: lss                     # Options: lss, bmmc, bm_threshold, bm_binning, bin_size, smoothing, ndbd_shift
  subcommand: dq                    # For LSS: dq or sscl
  lss_data_path: null               # Null defaults to cfg.infrastructure.data_files.lss_data_path
  datasets: [3601, 3602, 3603, 3604, 3605, 3606, 3607, 3608, 3609, 3610, 3611, 3612, 3613, 3614, 3615]
  n_dq: 100                         # For dq: random parameter draws per dataset
  dq_seed: 42
  pm1: false                        # If true, uses precomputed +/-1sigma sets
  chains: 2
  draws: 5000
  bias_calibration: "studies/example_bias_study/bias_calibration.json"
```

## 5. Storage Architecture & Artifact Lifecycle

```text
fit_data/
  roi_2400_2570/thr200/h2uv_b2.5/
    input/
      data.h5
      <component>_<input_UUID>.h5
    output/
      fit_<output_UUID>.h5
      fit_<output_UUID>.nc
  studies/
    example_lss_study/
      study.yaml
      example_lss_study.manifest
      example_lss_study.sqlite
      results.csv
      syst_summary.json             # Per-dataset and combined mode/HDI shifts
      tasks/
        syst_dq_ds3601.csv
        syst_dq_ds3602.csv
        ...
    example_syst_rate/
      study.yaml
      example_syst_rate.manifest
      example_syst_rate.sqlite
      delta_table.csv               # Summary of +sigma (right) and -sigma (left)
      syst_rate_summary.json        # Final mode, HDI, rate, and half-life limits
      combined_result.h5            # HDF5 carrying nominal_bc_post, marg_post, rate_post
      plots/
        delta_breakdown.png
        smeared_posterior.png
        rate_posterior.png
```

### 5.1 Storage Lifecycle Stages
1. **Inspection**:
   - `study.check_syst()` checks whether required input templates and previous task outputs exist.
2. **Execution**:
   - `study.run_syst()` executes systematic tasks in parallel, saving task files to `<study_dir>/tasks/syst_<point_id>.csv` (or `.h5`).
3. **Task Collection & Delta Calculation**:
   - `study.collect_syst_results()` reads task outputs, calculates mode shifts and 1-sigma edge deltas against nominal, updates `<study_name>.sqlite`, and exports `syst_summary.json`.
4. **Marginalisation**:
   - `study.run_marginalization()` computes quadrature sums $\sigma_{\text{right}}, \sigma_{\text{left}}$, smears the nominal posterior, converts to decay rate, samples PSA efficiency, writes `combined_result.h5` and `delta_table.csv`, and records summary metrics in SQLite.

## 6. Usage Recipes

### 6.1 CLI Usage (`run_study.py`)

```bash
# 1. Check systematic task completion status
python -m qpym2.run.run_study --study-dir studies/example_lss_study --check-syst

# 2. Execute systematic tasks
python -m qpym2.run.run_study --study-dir studies/example_lss_study --run-syst

# 3. Collect systematic results into syst_summary.json and SQLite
python -m qpym2.run.run_study --study-dir studies/example_lss_study --collect-syst

# 4. Check status of master rate marginalisation study
python -m qpym2.run.run_study --study-dir studies/example_syst_rate --check-syst

# 5. Execute full marginalisation, rate conversion, and half-life limit extraction
python -m qpym2.run.run_study --study-dir studies/example_syst_rate --marginalize
```

### 6.2 Python API Usage

```python
from qpym2.studies import assemble_study

# Assemble master rate study
study = assemble_study("studies/example_syst_rate")

# Check status of input systematics
status_df = study.check_syst()
study.print_syst_status(status_df)

# Run full marginalisation pipeline
results = study.run_marginalization()

print("Quadrature Widths:", results["sigma_right"], results["sigma_left"])
print("Rate Mode:", results["rate_mode"], "yr^-1")
print("Rate 90% C.L. Limit:", results["rate_p90"], "yr^-1")
print("Half-life Lower Limit (90% C.L.):", results["t_half_p90"], "yr")
```
