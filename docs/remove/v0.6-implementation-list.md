# QPyM2 v0.6 Implementation List: Storage Architecture

**Release:** `v0.6.0`  
**Focus:** Artifact Storage, Static Parameter Schemas, and Catalog Management  
**Reference:** [`docs/todos/data-management-and-artifact-store.md`](data-management-and-artifact-store.md)  
**Related:** [`docs/todos/model-parameter-taxonomy.md`](model-parameter-taxonomy.md)

---

## 1. Core Storage Package (`qpym2.storage`)

- [x] **`schemas.py`**: Static dataclasses for model points, fit specifications, manifests, and execution metadata (`StagingParams`, `InputParams`, `RunProfile`, `ExecutionMetadata`, `FileRecord`, `Manifest`).
- [x] **`hasher.py`**: Canonical serializer and deterministic SHA-256 derivation key generator (`derive_id` -> `<kind>_<sha256[:16]>`).
- [x] **`manifest.py`**: Reader, writer, and schema validator for sidecar `manifest.json` files.
- [x] **`store.py`**: Filesystem `ArtifactStore` manager (`objects/<type>/<prefix>/<artifact_id>/`).
- [x] **`catalog.py`**: Single-process SQLite indexer and query API (`catalog.sqlite`).
- [x] **`views.py`**: Generator for human-readable symlink hierarchies (`views/<campaign>/`) and flat `artifacts.tsv` indices.

---

## 2. Pipeline Runner Integration

- [x] **`run_create_staging.py`**: Publish staged ROOT/Parquet outputs with immutable `staging_id`; decouple staging cuts from model-specific ROI.
- [x] **`run_create_input.py`**: Produce identity-addressed `input.h5` artifacts referenced by derivation key.
- [x] **`run_single_fit.py`**: Pre-execution cache check (`store.exists()`) to skip completed fits; write `fit.h5`, `fit.nc`, and `manifest.json`.
- [x] **`run_toy_batch.py`**: Consolidated batch storage:
  - Default: Save summary fit results only into a single table (`results.parquet` or `results.h5`) per batch.
  - Optional: Bundle traces into a single multi-toy NetCDF file when full samples are requested.

---

## 3. Tooling & CLI

- [x] **`qpym2-catalog` CLI**: Command to index or rebuild `catalog.sqlite` by scanning artifact manifests (`qpym2-catalog index <store_root>`).
- [x] **Legacy Importer**: Read-only crawler for existing `data/M2v5Fits/tn_1ton/` directories to generate legacy manifests.
